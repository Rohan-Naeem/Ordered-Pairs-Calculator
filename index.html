What are ordered pairs?

An ordered pair is two numbers written together in a specific order, like (3, 7), that describe the location of a single point on a coordinate plane. It's called "ordered" because the sequence matters — (3, 7) and (7, 3) are different points.

The first number in the pair is the x-value, which tells you how far to move left or right from the center of the graph (the origin). The second number is the y-value, which tells you how far to move up or down. Together, x and y pin down exactly one location.

Ordered pairs and coordinates describe the same idea. When people talk about "the coordinates of a point," they usually mean the same x and y values written as an ordered pair.

How to calculate ordered pairs

Finding an ordered pair from any equation follows the same general process, whether the equation is a straight line or a curve:

  1. Choose a value for x.
  2. Substitute that value everywhere x appears in the equation.
  3. Simplify using order of operations to solve for y.
  4. Write the result as the ordered pair (x, y).
  5. Repeat with more x-values to build out a full table of points.

This works the same way for linear equations like y = mx + b and for curves like y = x^2 - 4 — only the substitution and simplification steps change.

Frequently asked questions

What is an ordered pair?

An ordered pair is a set of two values, written as (x, y), that gives a point's position on a coordinate plane. The first number is the x-value and the second is the y-value, and the order matters.

How do you find ordered pairs from an equation?

Pick a value for x, substitute it into the equation, and solve for y. The resulting x and y values together form the ordered pair (x, y). Repeat with different x-values to build a table of points.

What does (x, y) mean?

(x, y) is the standard notation for a point's location: x tells you how far to move horizontally from the origin, and y tells you how far to move vertically.

How do you calculate y from x?

Substitute your chosen x-value everywhere x appears in the equation, then simplify using order of operations to get a single number for y.

Can ordered pairs be negative?

Yes. Either or both values in an ordered pair can be negative, which places the point in a different quadrant of the coordinate plane.

What is the difference between an ordered pair and a coordinate?

They describe the same thing. "Coordinates" usually refers to the individual x and y values, while "ordered pair" refers to those two values written together as (x, y).
